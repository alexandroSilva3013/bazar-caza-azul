
  # Bazar Solidário Casa Azul

  This is a code bundle for Bazar Solidário Casa Azul. The original project is available at https://www.figma.com/design/uanEvDTbUzOuve2MNMjQ3r/Bazar-Solid%C3%A1rio-Casa-Azul.

  ## Guia de instalação para o grupo

  Consulte [GUIA-PARA-O-GRUPO.md](GUIA-PARA-O-GRUPO.md) para instalar Node.js/PostgreSQL, criar o banco, configurar o backend, criar o administrador local e executar os dois servidores. O guia também explica o que excluir ao compactar o projeto.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
